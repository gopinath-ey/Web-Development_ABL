Project Description This repository contains three website projects developed as part of the Web Development Activity-Based Learning (ABL) assignment. The websites are created using HTML and CSS to practice webpage structure, styling, and design.

Projects Included

1. 🎓 College Information and Admissions Website
A website designed to provide students with essential information about a college, including courses, admissions, facilities, and contact details. It helps students explore academic opportunities and understand the admission process.

2. ✈️ Travel Agency Website
A travel website designed to showcase destinations, tour packages, and travel services. It helps users explore travel options and plan their trips through a simple and user-friendly interface.

3. 🍔 Online Food Ordering Website
A food ordering website that allows users to explore food items, browse menus, and choose their favourite meals through an easy-to-use interface. It aims to provide a convenient and enjoyable online food ordering experience.

Technologies Used HTML5: Used to structure the webpages and organize content. CSS3: Used to style the webpages with colors, fonts, layouts, spacing, and visual effects. Learning Outcomes Through these projects, I gained practical experience in:

Creating webpages using HTML. Styling and designing webpages using CSS. Adding and arranging images and content. Working with colors, fonts, margins, and padding. Creating attractive layouts for different types of websites. Improving basic web development and design skills. Conclusion This ABL project helped me understand the fundamentals of web development through practical implementation. Creating three different websites improved my knowledge of HTML and CSS and gave me experience in designing visually appealing webpages.
